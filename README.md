# 🍰 Ailin Tattileri App

**Ailin Tattileri** ("Сладости Айлин") — это современное мобильное приложение для заказа кондитерских изделий, разработанное на Flutter. Проект объединяет в себе красивый клиентский интерфейс для покупки сладостей и мощную административную панель для управления магазином.

## 🚀 Особенности проекта

Приложение спроектировано с упором на **максимальную производительность** и **Premium UX**:

*   **Единая экосистема:** Одно приложение для клиентов и администраторов (с разграничением прав доступа).
*   **Мгновенная работа:** Использование оптимистичного UI, кэширования изображений и "умной" загрузки данных.
*   **Современный стек:** Flutter + Firebase (Auth, Firestore, Storage).
*   **Дизайн:** Адаптивный интерфейс с поддержкой темной темы и плавными анимациями.

## 🛠 Технологический стек

*   **Framework:** [Flutter](https://flutter.dev/) (Dart)
*   **Backend:** Firebase (Firestore NoSQL DB, Cloud Storage)
*   **State Management & Architecture:** Feature-first architecture, Services pattern.
*   **Navigation:** GoRouter (Declarative routing)
*   **UI/UX:** Google Fonts, CachedNetworkImage, Custom Design System.

## 📱 Функционал

### Для Клиента:
*   Просмотр каталога сладостей (Торты, Пирожные, Десерты).
*   Умная корзина покупок.
*   Быстрое оформление заказа.

### Для Администратора:
*   Управление меню (Добавление/Редактирование/Удаление товаров).
*   Загрузка фотографий товаров.
*   Просмотр и управление заказами в реальном времени.

## 🏁 Как запустить проект

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/your-username/ailin_tattileri_app.git
    ```

2.  **Установите зависимости:**
    ```bash
    flutter pub get
    ```

3.  **Настройка Firebase:**
    Этот проект использует Firebase. Вам необходимо создать свой проект в Firebase Console и добавить `firebase_options.dart`.

4.  **Запуск:**
    ```bash
    flutter run
    ```
